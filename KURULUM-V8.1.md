# TDA Luxury Akıllı Stok Yönetimi v8.1

## Düzeltilenler
- Supabase `never` insert TypeScript hataları giderildi.
- `PlatformShell` için zorunlu `title` özelliği eklendi.
- v8 veritabanı migration'ı korunmuştur.

## Kurulum
ZIP içeriğini projenin ana klasörüne çıkarın ve mevcut dosyaların üzerine yazın.

Ardından:

```bash
npm run typecheck
npm run lint
npm run build
```

Not: Supabase migration kullanıcı hesabındaki projeye uygulanmıştır.
