KURULUM
1. ZIP'i tdaluxury proje ana klasörüne çıkart.
2. Dosyaların üzerine yazılmasına izin ver.
3. Terminal:
   npm run build
4. Build başarılıysa:
   git add -A
   git commit -m "SEO V1 indexleme ve ic link optimizasyonu"
   git push origin main
