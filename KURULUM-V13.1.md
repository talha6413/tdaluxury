# TDA Luxury Müşteri Portalı v13.1

Bu paket v13 sürümündeki Supabase RPC TypeScript hatasını düzeltir.

## Değişen dosya
`components/customer/CustomerPortal.tsx`

## Kurulum
ZIP içeriğini proje kök dizinine çıkarın ve mevcut dosyanın üzerine yazılmasına izin verin.

## Kontrol
```bash
npm run typecheck
npm run lint
npm run build
```

Lint çıktısındaki `<img>` uyarıları derlemeyi engellemez.
