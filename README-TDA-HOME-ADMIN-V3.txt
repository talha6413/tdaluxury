TDA Luxury — Ana Sayfa Admin Canlı Bağlantı v3

Bu paket ana sayfadaki üç büyük bölümü admin panelindeki site_sections verilerine bağlar:

1) Hizmetler bölümü
- küçük başlık
- ana başlık
- açıklama
- buton metni
- buton bağlantısı
- hizmet kartları mevcut hizmet yönetiminden gelmeye devam eder

2) Hakkımızda / Salonumuz bölümü
- küçük başlık
- başlık
- açıklama
- buton metni
- buton bağlantısı
- görsel
- görsel pozisyonu

3) Danışmanlık bölümü
- küçük başlık
- başlık
- açıklama
- ana buton metni
- buton bağlantısı
- özel arka plan görseli için altyapı

Ayrıca:
- bölüm görünürlüğü admin panelinden çalışır
- bölüm sıralaması admin panelinden çalışır
- Hero zaten admin verisine bağlıdır

Kurulum:
1. ZIP'i tdaluxury proje klasörüne çıkarın.
2. Dosyaların üzerine yazılmasına izin verin.
3. Terminal:

git add .
git commit -m "Ana sayfa bolumlerini admin paneline bagla"
git push origin main
