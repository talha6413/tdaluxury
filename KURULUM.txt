TDA Luxury — Randevu Gün + Saat Güncellemesi

Bu paket:
- Müşteri hesabına giriş bölümünü randevu sayfasından tamamen kaldırır.
- Sabah / Öğleden sonra / Akşamüstü seçeneklerini kaldırır.
- Sol tarafta önümüzdeki 12 açık günü gösterir.
- Sağ tarafta 09:00–19:30 saatlerini 30 dakikalık aralıklarla gösterir.
- Pazar günlerini otomatik gizler.
- Seçilen gün ve saati WhatsApp mesajına ekler.
- Randevu sayfası metinlerini yeni akışa göre günceller.

Kurulum:
1. ZIP'i tdaluxury proje ana klasörüne çıkart.
2. Dosyaların üzerine yazılmasına izin ver.
3. Terminal:
   npm run build
4. Build başarılıysa:
   git add -A
   git commit -m "Randevu gun ve saat secimini yenile"
   git push origin main
