bulunmayan sayfalarda devreye girer.

SITEMAP

lastModified eklenir. Diğer hizmetlere sahte güncelleme tarihi verilmez.

KURULUM
1) ZIP'i TDA Luxury proje ana klasörüne çıkart ve app/sitemap.ts üzerine yazılmasına izin ver.
2) UYGULA-SEO-V5.bat dosyasına çift tıkla.
   Bu dosya ServicePage.tsx'i UTF-8 karakterlerini bozmadan güvenli şekilde yamalar.
3) Terminalde:
   npm run build
4) Build başarılıysa:
   git add -A
   git commit -m "SEO V5 ozgun hizmet icerikleri"
   git push origin main

DEPLOY SONRASI KONTROL
- /bolgesel-incelme H1 = Uşak Bölgesel İncelme

- /tirnak H1 = Uşak Tırnak Hizmetleri
